# 角色規格

產品總體規格見 [SPEC.md](../SPEC.md)，用語見 [CONTEXT.md](../CONTEXT.md)。

## 模型與動作

- 使用 [Kenney Cube Pets](https://kenney.nl/assets/cube-pets)，提供貓、小雞、狗、豬、牛。
- 叫聲分別挑選輕喵、輕啾、輕聲短叫、柔和鼻哼、低沉短哞；音檔需試聽，避免尖銳、連續或驚嚇感強的聲音。
- 模型、預覽與聲音需保留來源及授權記錄。Cube Pets 不附音效，需另外取得。
- 行走呈現向前小跳，轉彎平順轉向，停止後待機。
- 按下停止時立即停止水平前進，原地平順落地；重新開始時從原處繼續。

## 角色生命週期

- 世界最多一隻角色。
- 新角色在有效道路的最大群組中出生，預設直接開始行走。
- 最大群組以有效道路 Tile 數量判斷；同大小時隨機選一組，再從組內隨機選出生道路。
- 加入角色、重新安置與讀取存檔後的出生均使用相同選路規則。
- 孤立的有效道路允許加入角色。無相鄰連通道路時原地待機，保留行走啟用狀態；補通道路後自動繼續。
- 使用者手動停止後，補通道路不會自動開始。
- 更換角色保留位置、方向、速度與移動狀態。
- Build／Relax 切換不影響角色狀態。
- 目前位置仍有效時留在原處；其他群組變大不會觸發傳送。
- 所在道路失效時重新安置，保留角色種類、速度與行走啟用狀態；世界中沒有任何有效道路時移除角色。
- 無道路而移除角色後，重建道路不會自動重新加入角色。

## 道路移動與歷史

- 僅通過旋轉後雙向出口相通的可通行道路；橋樑、河流及建築不可通行。
- 岔路隨機選路，優先排除來路；沒有其他方向時允許折返。完全無連通方向時待機。
- 行走路徑需沿路面銜接入口與出口，包含彎道與岔路；不可穿越路面外的地景。
- 道路修改後保留仍有效的位置，平順接回可行道路。
- 速度以滑桿控制，預設 1×，範圍 0.5×–2×；1× 在直路上約四秒一格，彎道依實際路徑長度行走。
- 速度影響移動與步頻，不影響叫聲間隔或環境音播放速度。
- 角色操作不加入建造歷史。Undo／Redo 不還原角色種類、位置、行走啟用狀態或速度，也不復活已移除的角色。
- Add、Replace、Rotate、Remove、Undo、Redo 造成的道路變化，均重新檢查角色位置與可行路徑；這是適應目前道路，不是復原角色歷史。
- 道路修改後，目前位置仍有效就原地續行並重算路徑；失效時套用重新安置或移除規則。

## 存檔與恢復

- 角色持久化只包含角色種類及行走啟用狀態；無角色時記錄空值。
- 不儲存角色位置、方向、格內進度、跳躍姿勢、速度、視角或叫聲倒數。
- 重新進入世界時，依最大道路群組規則重新出生，恢復行走啟用狀態；速度回到 1×，視角回到 Builder View。
- 恢復已啟用行走的角色時，有路就走，無連通方向就待機；若完全沒有有效道路則移除角色。
- 加入、更換、移除角色及手動開始／停止時儲存；不因每幀移動持續寫入 LocalStorage。
- 世界 Tile、Build／Relax 模式與既有音訊設定仍依現有規則儲存。
- 腳步聲與寵物叫聲開關預設皆開啟並保存，面板展開狀態不保存。
- 無效或不相容的存檔應清除並安全回到空白狀態。
- 關閉網頁期間不計算角色行走進度。

## 角色聲音

- 叫聲使用低音量短音檔，播放結束後重新等待隨機 20–45 秒，不重疊播放。
- 停止行走時仍會偶爾叫；更換角色時停止舊叫聲，重新計算間隔。
- 加入、更換角色、恢復世界、恢復音訊播放、解除靜音或重新開啟叫聲後，重新等待 20–45 秒再播放叫聲。
- 暫停、靜音或關閉叫聲會停止當下叫聲並取消倒數，恢復後不補播。
- 所有角色共用輕柔腳步聲，每次行走落地觸發，配合速度與步頻。
- 腳步聲不得疊加；停止落地、孤立道路待機與背景分頁不觸發。
- 右上齒輪提供「腳步聲」「寵物叫聲」獨立開關，Build／Relax 與無角色時均可調整。關閉腳步立即停止當下腳步，重新開啟只等待下一次有效落地。
- 叫聲與腳步聲保持輕柔；音效無法播放時不累積補播。
- 音訊暫停、靜音與主音量控制全部聲音，不影響角色移動。
- 不新增叫聲、腳步聲各自的音量控制。
- 移除角色時取消叫聲排程及角色音效；離開世界頁面時停止全部聲音並清理播放資源。

## 背景分頁

- 分頁進入背景時，暫停角色實際移動與腳步聲，保留行走啟用狀態。
- 環境音與間隔叫聲維持播放，仍受主音量、靜音與音訊暫停控制。
- 回到前景時依原行走啟用狀態繼續，不補跑背景期間距離，不集中補播延遲的叫聲。
- 瀏覽器可能限制背景計時或暫停分頁，不保證背景叫聲精準準時；恢復時避免累積觸發。

## Character Listener

- 只要有角色，就以角色位置決定環境音，與 Builder／第一／第三人稱視角無關。
- 近處 Tile 聲音較清楚，遠處逐漸淡出；初始有效距離以約三格為調整起點，實際衰減需試聽。
- 朝向不影響混音，不新增左右聲道計算；移動時平順更新，避免聲音跳變。

- 角色停止仍持續播放局部環境音；重新安置後平順過渡到新位置的混音。
- 移除角色時平順回到 World Listener；仍有角色的重新安置不切回 World Listener。

## 角色鏡頭

- 提供第三人稱與第一人稱視角，平滑切換並跟隨角色方向。
- 不提供自由轉頭；依總體規格，不提供跟隨距離控制或碰撞避讓。
- 第三人稱鏡頭高度保持穩定；第一人稱跟隨角色實際小跳與停止落地，第一人稱隱藏自身模型，動畫與腳步聲仍持續更新。
- 移除角色時回到 Builder View。
- 只有 Relax Mode 提供視角控制；Build Mode 固定使用 Builder View，不顯示視角控制。切回 Build 時自動回到 Builder View，恢復離開前的觀看位置與目標；角色、音訊與行走啟用狀態不受影響。
- 建造操作與 Undo／Redo 限定 Build Mode 的 Builder View；視角只存在暫態狀態，不寫入存檔或歷史，重入世界回到 Builder View。

## 驗收條件

- 五種寵物皆可加入、更換與移除；無道路不可加入，孤立道路可待機。
- 直路、彎道、岔路、死路與旋轉出口均沿路面行走；速度控制與停止生效。
- 道路修改及復原／重做後不走進無效道路，也不倒帶角色；補通道路時依行走啟用狀態續行。
- 叫聲間隔為 20–45 秒、不重疊、不補播；腳步與落地同步，停止及背景返回不多播。
- 叫聲、腳步與環境音遵守主音量、靜音與暫停；聲音開關重新進入世界後保留。
- 更換、移除角色及離開世界後不殘留舊角色聲音。
- 靠近、遠離地塊、停止及重新安置時聲音連續；原地轉向不改變混音，移除角色後回到世界混音。
- 第一／第三人稱平順切換並跟隨；第三人稱高度穩定，第一人稱跟隨小跳與停止落地。
- 只有放鬆模式提供角色視角，建造模式回到世界視角；視角切換不中斷角色或聲音。
