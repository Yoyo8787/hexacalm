# 角色資產與授權

## 角色模型

貓、小雞、狗、豬與牛使用 [Kenney Cube Pets](https://kenney.nl/assets/cube-pets) 的模型、預覽與貼圖，採 CC0 授權，原文見 [Cube Pets 授權](../public/license/CubePets-License.txt)。

## 角色聲音

五種角色各有叫聲，共用一種輕柔腳步聲。聲音素材另取自 Pixabay，與模型授權分開；名稱、作者、來源與授權見 [音效來源與授權](../public/audio/ATTRIBUTION.md)。

## 道路素材

道路模型與衍生路面資料來自 Kenney Hexagon Kit，採 CC0 授權，原文見 [Hexagon Kit 授權](../public/license/License.txt)。

角色的加入、移動、聲音與視角行為見 [角色規格](./character-spec.md)。
